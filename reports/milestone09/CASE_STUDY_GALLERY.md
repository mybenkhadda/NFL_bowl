# Case-study gallery — design (Milestone 09)

> The executed gallery, with real athletes, three views per case and the figure of each, is written by notebook 09G to `CASE_STUDY_GALLERY_EXECUTED.md`. No athlete is named here because no case has been selected yet: selection is a deterministic rule run on the data.

| # | Case type | Selection rule (pre-draft only) | What it shows |
|---|---|---|---|
| 1 | Same forty, different acceleration curve | forty within 0.03 s, 10-yard split matched when recorded; largest distinguishable band-acceleration difference | the core discovery |
| 2 | Same top speed, different speed development | tracked top speed within 0.05 yd/s; largest distinguishable 4 → 8 yd/s difference | equal endpoint, different route |
| 3 | Same first 10 yards, different later acceleration | split within 0.02 s, speed at 10 yd not distinguishable; largest late-run difference | where the 10-yard split stops seeing |
| 4 | Similar official tests, distant fingerprints | forty, split, weight, height matched; largest TCN-B distance | a mathematical pattern — prompt to compare curves |
| 5 | High-confidence movement difference | both high evidence tier, ≥ 2 distinguishable features | the strongest measured contrast |
| 6 | Apparent difference inside the uncertainty | largest speed-development difference that is NOT distinguishable | what not to over-read |
| 7 | Position-specific comparison | top-ranked pair of each position not already used | one per position |
| 8 | Repeat-attempt inconsistency | largest difference in attempt-to-attempt range | stability matters |
| 9 | Tracking-quality limitation | high vs low evidence tier, closest forty | when the recording, not the athlete, limits the reading |
| 10 | Similar movement, observed NFL movement shown | no distinguishable feature, both ≥ 50 tracked NFL windows (exposure count only) | two similar Combine runs can be followed by any NFL movement — an illustration, not evidence |

Each case carries a scout view, a position-coach view and a general-manager view, a practical follow-up, and its limitations. A type without a qualifying pair is reported as absent.
